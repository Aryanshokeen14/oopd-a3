## Overview
Extends the pandemic simulation with epidemiological experiments and analysis.

## Implemented Features
- All Part A, B, C, and D features.
- Default epidemic spread analysis.
- Transmission-rate experiments.
- Vaccination and herd-immunity analysis.
- Mask intervention experiments.
- Lockdown intervention experiments.
- Combined intervention analysis.
- Comparison with the standard SIR model.

## Analysis
The experiments investigate:
- Epidemic progression over time.
- Outbreak behaviour under different transmission rates.
- Effect of vaccination on infection spread.
- Effect of masks and lockdowns on peak infections.
- Differences between grid-based simulation and standard SIR equations.
