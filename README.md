## Overview
Implementation of a sequential grid-based pandemic simulation.

## Implemented Features
- Two-dimensional grid simulation.
- Susceptible (S), Infected (I), Recovered (R), Vaccinated (V), and Deceased (D) states.
- Infection and recovery mechanisms.
- Configurable simulation parameters.
- Daily population statistics.
- CSV output generation.

## Technologies
- C++17
- Make
- Apple Clang

## Compilation and Execution
```bash
make
./pandemic_sim
```
